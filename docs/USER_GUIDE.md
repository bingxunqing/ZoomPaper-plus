# ZoomPaper Plus 功能与操作指南

ZoomPaper Plus 是面向中文用户的 AI 论文阅读工具，覆盖论文收集、整理、阅读、翻译、问答、复习和阅读计划。

## 论文库

- **全部论文**：显示所有未删除论文。收藏、未分类和普通文件夹都来自这里。
- **收藏**：全部论文中已加星标的论文。
- **未分类**：尚未加入任何文件夹的论文。
- **回收站**：保存已删除论文；可恢复，清空后才永久删除。
- **文件夹**：一篇论文可以同时加入多个文件夹。右键文件夹可新建子文件夹、重命名或修改颜色。
- **快速多选**：长按论文进入多选；按住复选框向上或向下拖动，可连续选择多篇。点击空白处或完成操作后退出多选。
- **列表与卡片**：可切换两种布局，并按添加时间、最近阅读或标题排序。

## 收集与解析

- 从电脑导入 PDF，解析正文、标题、作者、摘要、期刊或会议，并建立检索索引。
- Chrome / Edge 扩展可从常见论文网站直接加入 ZoomPaper Plus。
- 论文有关联 GitHub 仓库时，阅读页提供直达按钮。

## 阅读

- PDF、中文译文与 AI 博客在同一阅读工作区。
- 选中文字可快速翻译；简短术语只返回精炼中文释义。
- 支持高亮、批注、页面定位和阅读时长记录。

## AI 助手

- 对当前论文提问，回答附带原文引用，可跳回对应页。
- 快速模式适合直接问答；深度模式会分步检索、分析并按需联网。
- 生成期间可以切换论文或页面，任务会继续运行。
- 知识库问答可跨多篇论文检索。

## 学习与复习

- AI 博客将论文整理为易读内容。
- 费曼学习按概念建立独立会话，通过追问和测验检查理解。
- 测验、阅读计划和时间线帮助安排与复盘阅读。

## 设置

- MinerU 用于 PDF 解析。
- OpenAI、Anthropic、Gemini、DeepSeek 或兼容接口用于翻译和 AI 功能。
- API 信息保存在本机配置中。

## 常用操作

- 将鼠标停在图标上可查看用途。
- 右键论文可打开与“更多”按钮相同的操作菜单。
- `Esc` 退出多选；`Command/Ctrl + A` 全选当前列表；`/` 或 `Command/Ctrl + F` 聚焦论文库搜索。
