# 设置改版审核方案（精简版）

状态：已按审核结果写入应用，版本号仍为 0.4.2。

## 保留六个板块

| 板块 | 内容 |
| --- | --- |
| 标题与启动 | 统一标题语言、论文库/标签/概览/阅读历史独立语言、概览摘要语言；恢复上次打开的论文 |
| 论文阅读 | 打开后标记在读、读到末页标记已读、默认显示右侧 AI 助手 |
| 阅读伙伴 | 显示伙伴、角色动画、阅读气泡、任务气泡；无独立通知或位置设置 |
| AI 模型与 API | 沿用现有 Provider 管理、API Key、Base URL、可手填默认模型、联网服务与搜索模型；不新增用途分配或对话默认值 |
| 导入与解析 | MinerU API、自动解析、输入同时解析数量；会议/DOI 补全、标题摘要翻译、自动全文翻译；扩展状态、安装引导和打开目录；去掉重复论文偏好 |
| 数据与存储 | 存储路径、完整备份/恢复、重建索引、缓存清理、清空回收站 |

布局沿用左侧分类搜索、右侧整块滚动。只保留短标签，移除 ⓘ 说明图标。移除外观、字号、密度、默认视图、默认排序、长按阈值、缩放、默认阅读内容、启动页面、检索默认值、快捷键与关于设置。功能帮助入口保留在原本帮助板块。

## 缺少中文时的选择

1. 用户选择中文优先或双语时，统计该位置涉及的非回收站论文。
2. 缺少标题/摘要译文时弹窗，分别显示待译标题、摘要数量。
3. **全部翻译**：仅补齐缺失标题与摘要，保留已有译文和英文元数据，使用当前 AI 服务；不触发全文翻译。
4. **保留英文**：当前缺失项继续显示英文，已有中文仍按展示偏好显示，不回退整个设置到英文。
5. 关闭弹窗或 Esc 等同保留英文，不产生请求。每次设置动作只提示一次，不在切换标签或打开论文时重复打断。
6. 翻译后台执行，成功项立即更新；失败项保持英文，汇总失败并允许重试。无已配置 AI 时先配置服务，不假装已翻译。
7. 用户切换显示不修改正文或引文；搜索同时匹配中英文标题与摘要。
8. “全部”范围需在弹窗写明。统一设置为全库非回收站论文；特定位置也按该位置的可展示范围，不默默扩大到回收站。

原型使用 4 个标题、3 个摘要的演示数量。点击“补全中文”可查看弹窗；改变语言也会触发。点击全部翻译只模拟补译效果，不发 API 请求。

## 右侧 AI 助手

仅控制阅读器右侧的问答/测验面板。关闭后阅读区域扩展；不影响知识库问答，也不取消后台生成。原阅读器仍提供临时开启入口。默认开启，符合现有行为。

## 解析并发数

改为整数输入框，默认 2、最小 1，允许用户填写，不再只有 1/2 的下拉框。空值、零、负数、小数不得保存。后续实现需将队列调度同步改为按配置运行；降低并发不打断已开始任务，增加并发再调度排队任务。

## 扩展安装

文件夹版无法由普通 App 直接静默安装到 Chrome。采用“安装扩展”引导：准备固定目录、协助打开 Chrome 扩展管理页并提供路径，用户首次加载已解压目录。后续覆盖同一目录，用户重新加载。商店版可直接打开商店页，仍由用户确认安装。

参考：[Chrome 官方分发方式](https://developer.chrome.com/docs/extensions/how-to/distribute)、[其他安装方式](https://developer.chrome.com/docs/extensions/how-to/distribute/install-extensions)。不通过修改用户 Chrome 配置或企业策略模拟安装成功。原型不真正安装扩展。

## 数据功能边界

备份/恢复仍为拟新增功能：需包含 PDF、数据库、笔记、会话、译文与状态，排除 API 密钥；恢复前校验并备份当前库。路径迁移、缓存清理和清空回收站均说明实际操作并确认。不能把清理缓存当成删除论文。
