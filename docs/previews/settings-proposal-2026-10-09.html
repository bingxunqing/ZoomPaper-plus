设置

本轮方案

这是独立交互原型，不连接 API、不修改论文库。所有新增设置均待审核；这里的连接测试和数据操作只演示流程。

优先落地

  1. 设置分类与全文搜索；服务连接分别归入 AI、导入解析、检索。
  2. 统一标题语言，并允许论文库、论文标签、右侧概览、阅读历史独立覆盖。没有中文时回退原文，不因切换显示调用 AI。
  3. 阅读伙伴独立板块；保留恢复标签、字体、列表密度、阅读状态、任务通知等高频偏好。

第二批

按用途覆盖模型、连接检测、任务并发限制、数据备份与恢复、快捷键自定义。备份需要包含 PDF、数据库与生成内容，排除 API 密钥，并提供恢复前校验。

设置规则

普通偏好自动保存；API 配置在表单确认保存，并允许手动填写模型名。耗费 API 的自动操作显式开关。维护与删除操作再次确认；不增加自动清空回收站。

默认值建议

标题中文优先，摘要中文优先；未有译文使用原文。其他位置默认跟随统一设置，可设原文、中文优先或中英双语。默认列表、最近阅读排序、适合宽度、恢复工作区；联网提问默认关闭，由用户主动开启。
