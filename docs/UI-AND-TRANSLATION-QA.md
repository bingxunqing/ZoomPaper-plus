# UI 与阅读体验改进（2026-09-16）

## 已完成

- 统一暖白背景、深青强调色和侧栏/内容层级；调整论文库留白、文件夹宽度、网格边界和窄窗口操作区换行。
- 提高中文对照译文的文字对比度；补充导航、返回按钮、高亮色板和视图切换的可访问标签。
- PDF、博客和译文共用划选速译：点击发起，附带附近上下文，只要求中文释义或译文，独立于问答和全文翻译。
- 速译限制为 2000 字，附近上下文最多 1000 字；后端 45 秒超时，失败可重试，过期请求不会覆盖新选区。
- 浮层按实际大小限制在窗口内；滚动速译结果不会误关博客/译文浮层。
- 论文库支持标题、作者和摘要即时筛选，以及无结果清除入口。
- 打开论文记录最近阅读时间，支持继续阅读入口和最近阅读排序；普通元数据读取保持只读。
- 修复排序框显示内部英文值、一级文件夹标题未显示文件夹名称、解析错误提示被刷新清除等问题。
